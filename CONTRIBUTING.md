# 🤝 Contributing & Feedback Guide

Thank you for exploring **CineDB**!

This repository serves as the official portfolio showcase and architectural reference for the live application at [cinedb.xyz](https://www.cinedb.xyz).

---

## 💡 How You Can Participate

1. **Bug Reports & Edge Cases:** If you observe an anomaly on [cinedb.xyz](https://www.cinedb.xyz) (e.g., broken player mirror, UI overflow on specific mobile viewports, TMDB API pagination mismatch), please [open an issue](https://github.com/Msumankumar05/CineDB.xyz/issues) with reproduction steps.
2. **Feature Suggestions:** Feel free to open a discussion or issue suggesting new regional catalogs, player improvements, or UI refinements.
3. **Architecture & Code Review:** Feedback from fellow engineers, recruiters, and UI designers is warmly welcomed.
